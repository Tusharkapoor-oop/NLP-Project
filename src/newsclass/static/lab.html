Notes

What this page actually tests

Independent calls

Each card is a separate POST /v1/predict with a tier override. No result is copied from its neighbour, so the comparison reflects three real inferences.

Two latencies

“Server” is the model's own predict_proba time. “Round trip” adds HTTP, JSON and the browser on this machine. Neither is a benchmark, but the gap between them is real.

Honest fallback

If a tier is not installed, the API serves the best available desk. The card names the desk that actually answered instead of pretending the requested one did.

Not an accuracy claim

A handful of paragraphs is a smoke test. Published accuracy comes from the stratified held-out audit: gold 92.4%, silver 89.1%, bronze 89.9%, each with its own calibration error.
