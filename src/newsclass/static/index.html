    03 / Method

    A pipeline that refuses to lie.

    One command trains what is missing, loads every artifact through the real registry, checks probability shape, merges the registry, and blocks serving unless the macro-F1 gate passes.

    1. 01

      Dataset

      AG News from the Hugging Face Hub. One fixed split, one seed, no bundled scraped data.

      0 rows
    2. 02

      Train

      TF-IDF, Word2Vec + BiLSTM, and DistilBERT — the same preprocessing module at train and serve time.

      0 tiers
    3. 03

      Gate

      Every artifact is re-scored on held-out data. Below the macro-F1 threshold, the pipeline exits non-zero.

      0 gate
    4. 04

      Serve

      FastAPI with readiness probes, fallback routing, Prometheus metrics and a request id on every response.
